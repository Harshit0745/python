# 🐍 Snake Water Gun Game

A simple Python mini project based on the classic Snake, Water and Gun game, where the user plays against the computer.

### Features
- Play against the computer.
- Computer randomly selects Snake, Water or Gun.
- Displays win, lose or draw results.
- Handles invalid user input.

### Technologies Used
- Python
- Random Module

### How to Run

```bash
python main.py
```

### Game Rules
- Snake beats Water.
- Water beats Gun.
- Gun beats Snake.
- Same choices result in a draw.
